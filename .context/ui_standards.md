# STANDARDS UI & CSS - PROJET FEUILLE DE PERSO

## 1. Design System
- **Couleurs** : Utiliser les variables CSS définies dans `index.css` (ex: `--color-accent`).
- **Icons** : Utiliser `lucide-react`.
- **Animations** : Privilégier Framer Motion pour les transitions complexes, Vanilla CSS pour les micro-interactions.

## 2. Composants
- Utiliser le composant `logger` pour tout retour d'information.
- Maintenir le support du mode sombre/clair via les classes Tailwind `dark:`.

## 3. Responsive
- Approche "Mobile First".
- Vérifier les débordements (overflow) sur les petits écrans.
